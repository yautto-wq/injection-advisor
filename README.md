# OMC Smart Injection Advisor

OMC Smart Injection Advisor 是給超群機械（OMC）業務與客戶使用的射出成型前期評估工具。

## 線上體驗

👉 **[點我直接使用 Injection Advisor 網頁版](https://injection-advisor.vercel.app)**

## v2.0 主要功能

- 五種資料入口：精準數據、2D尺寸、克重+穴數、3D數據、舊機置換
- 射出成型機鎖模力與機台級距初步選型
- 修正模具柱間距升級後的 Fitment 判斷
- 不再在舊機置換模式寫死 200g 射出重量
- 克重+穴數模式明確標示投影面積為粗估
- Cycle Time 即時估算與微調
- 產能估算：理論產量、稼動率、良率、月產能、所需設備台數
- OS 系列機台占地 / 廠房 Fit Check
- 機台尺寸資料納入 OS-50 / 80 / 110 / 140 / 180 / 250 / 320 / 420 / 550 與對應射座
- 省電 / 電費比較：支援實測、OMC 測試、人工估算三種來源
- OMC Advisor 檢查提醒
- 可列印 / 另存 PDF

## 注意

目前選型、柱間距、射出容量、Cycle Time 與機械尺寸屬前期評估工具。正式報價與下單前，仍應以 OMC 官方規格、材料牌號、模具圖與實機試模條件再次確認。
