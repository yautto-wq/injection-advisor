# OMC Smart Injection Advisor

OMC Smart Injection Advisor 是給超群機械（OMC）業務、工程與客戶使用的射出成型前期選型、調機與成本評估工具。

## 線上體驗

👉 **[點我直接使用 Injection Advisor 網頁版](https://injection-advisor.vercel.app)**

## v3.2：客戶導向 AI 選型流程

新版不再先要求客戶填一大堆射出機工程欄位，而是先問：

### 你目前手上有哪一種資料？

**A｜快速 AI 選型**
- 只有成品尺寸、重量、材料、水口、穴數或需求產量
- 沒有模具圖也可以開始
- 適合業務初談、新產品、尚未開模

**B｜工程精準選型**
- 有模具尺寸、CAD、總投影面積、Shot、現有機台或實測數據
- 適合既有模具、換機、正式工程確認

兩條路最後都會產生同一份 OMC 評估報告，但會清楚標示：
- 已確認資料
- 系統估算資料
- 待 OMC 官方規格確認資料

## AI 選型邏輯

### 01 材料與產品需求
客戶輸入：
- 材料 / 牌號
- GF / CF / 礦粉 / FR 與比例
- 一般 / 精密 / 醫療 / 光學 / 高外觀
- 重量一致性要求

### 02 產品與產量
客戶輸入：
- 單件重量
- 穴數；不知道時可輸入月需求反推
- 最大投影長 × 寬
- 最薄肉厚
- 熱澆道 / 冷澆道
- 水口重量
- Cycle Time
- 已知最高射壓（選填）

系統計算：
- 每模 Shot
- 熔膠體積
- 投影面積
- 鎖模力級距
- 所需最低塑化能力

### 03 模具 / CAD / 現場
- 模具寬、高、模厚、模重
- 開模距離 / 頂出行程
- 廠房空間
- ASCII DXF 外框初判
- 520 × 750 mm 這類長方形模具不再錯誤要求「寬、高都必須小於柱間」
- 柱間只作拉桿干涉方向判斷；模板尺寸、模厚、開距等需再比對官方機台規格

### 04 機台規格結果
結果頁直接顯示：
- OMC 建議噸數
- 柱間淨距
- 可搭射座
- 機台寬 / 高 / 長度範圍
- 模具安裝判斷
- 資料可信度

### 05 射出單元 / 螺桿 AI 規格窗口
目前已將公開型錄中的射座 / 螺桿直徑、理論射出容積、最大射壓與 PS 塑化能力建入初選資料庫，系統會先自動排名：
- Shot 重量 / 體積
- 建議料管可用射量窗口
- 射壓需求方向
- 最低塑化量 kg/h
- L/D / 深淺溝方向
- 有卡口 / 無卡口止逆環方向
- 標準 / 耐磨 / 耐腐蝕 / 高耐磨雙合金方向

正式 Ø40 / Ø46 / Ø52 等候選會依型錄數據直接顯示並可人工改選。選型主要比較 Shot 使用率、Cycle 所需塑化量與射壓餘裕。後續仍應用 OMC 最新正式規格表核對：
- 螺桿直徑
- 最大射出體積 / 重量
- 最高射壓
- 射出率
- 塑化量
- L/D
- 壓縮比

匯入後，就能把目前的「需求窗口」直接配對成正式推薦。
