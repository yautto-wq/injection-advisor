# OMC Smart Injection Advisor

OMC Smart Injection Advisor 是給超群機械（OMC）業務、工程與客戶使用的射出成型前期選型、調機與成本評估工具。

## 線上體驗

👉 **[點我直接使用 Injection Advisor 網頁版](https://injection-advisor.vercel.app)**

## v4.2：客戶導向 AI 選型流程

新版不再先要求客戶填一大堆射出機工程欄位，而是先問：

### 你目前手上有哪一種資料？

**A｜快速 AI 選型**
- 只有成品尺寸、重量、材料、水口、穴數或需求產量
- 沒有模具圖也可以開始
- 適合業務初談、新產品、尚未開模

**B｜工程精準選型**
- 有模具尺寸、CAD、總投影面積、Shot、現有機台或實測數據
- 適合既有模具、換機、正式工程確認

兩條路最後都會產生同一份 OMC 評估報告，但會清楚標示：
- 已確認資料
- 系統估算資料
- 待 OMC 官方規格確認資料

## v4.2：以客戶用途與未來性為核心的選機邏輯

新版先問「這台機器要替客戶做什麼」，再進入工程計算。

### 01 使用策略
- 泛用 / 未來型：工程條件允許時，優先配置較大射座，保留換模與產品成長空間
- 高速量產：較大射座 + 中大螺桿，優先看塑化量、Cycle 與射壓
- 專用機：不強制放大射座，針對固定產品最佳化
- 特用機 / 特殊材料：依材料與特殊製程條件優先

### 02 產品類別
- 一般民生
- 薄壁高速
- 包裝 / 杯盒
- 醫療 / 多穴
- 透明 / 光學
- 大型厚壁 / 長 Cycle
- 工程塑膠 / GF
- 回收料 / 混料

產品類別會改變螺桿直徑的推薦權重，而不是所有產品都用同一個 Shot 百分比。

### 03 射座與螺桿分開決策

**射座策略**
- 泛用 / 未來 / 高速：優先較大射座
- 專用 / 特用：以目前產品最佳化

**螺桿直徑策略**
- 泛用：中間直徑優先
- 高速：中大直徑，但要保留射壓
- 薄壁：偏小 / 中直徑，保留高射壓
- 大型長 Cycle：依 Shot 容量，不為塑化速度盲目放大
- 醫療 / 精密：避免 Shot 使用率過低，兼顧重複性與停留
- 工程料 / GF：直徑之外，同時提高耐磨、雙合金與止逆環權重

### 04 未來性問題
客戶可選目前產品未來 Shot 可能增加：
- 0%
- +20%
- +50%
- +100%

另外會詢問未來是否換材料、增加穴數或縮短 Cycle。

### 05 三種結果方案
每次選型同時輸出：
1. **OMC 建議方案**：依公司「泛用機優先較大射座」策略
2. **專機最佳方案**：只針對目前產品最佳化
3. **未來升級方案**：把未來 Shot 成長一起算入

每一個方案都會顯示：
- 射座
- 螺桿直徑
- Shot 使用率
- 未來 Shot 使用率
- 理論射出容積
- 最大射壓
- PS 塑化能力
- L/D
- 為什麼這樣選
- 為什麼沒有再往更大螺桿選

### 06 模具 Fit Check
重新納入：
- 模板尺寸
- 柱間淨距
- 模具方向
- 模厚 / 開距 / 頂出待確認

例如 520 × 750 mm 模具在 250T 會同時看 866 × 866 mm 模板與 580 mm 柱間，不再錯誤要求模具兩個方向都必須小於柱間。

### 07 射出資料庫
沿用 50T–550T 及 i05–i55 型錄資料，包括：
- 螺桿直徑
- 理論射出容積
- 最大射出壓力
- L/D
- PS 塑化能力

PS 塑化能力只作初選基準；PET / PC / GF 等實際塑化能力仍需材料與試模確認。

## v4.2：必選條件 + 高速 EHIII + A4 單頁報告

### 必選條件
客戶可以把條件設成「硬條件」：
- 必須高速蓄壓 / 氮氣加速
- 必須伺服節能 DS
- 必須雙合金料管 / 螺桿

硬條件會直接排除不符合的方案；沒有設成必選的項目才由 AI 做推薦。

### 高速產品規則
以下情況自動把高速蓄壓列為必選：
- 機台策略 = 高速量產
- 產品類別 = 薄壁高速
- 產品類別 = 包裝 / 杯盒
- 客戶手動指定「必須高速蓄壓 / 氮氣加速」

高速硬條件下，標準 EH / EH-DS 不作首選：
- 高速必選：EHIII / EHIII-DS
- 高速 + DS 必選：EHIII-DS
- 非高速但 DS 必選：EH-DS / EHIII-DS
- 沒有硬條件：EH-DS 為泛用節能推薦，可依預算選 EH

### A4 單頁選型報告
PDF 改為一張 A4 摘要，標題：
- OMC OUTSTANDING MACHINERY
- Outstanding Machinery Mfg. Co., Ltd.
- 超群機械工業股份有限公司
- 射出成型機 AI 選型報告

單頁內容包含：
- 客戶 / 聯絡人 / 產品 / OMC 業務
- 硬條件與推薦條件
- 建議完整機型（例如 OS250EHIII-DS）
- 產品與製程資料
- Shot / 鎖模力 / 模具 Fit
- 三種射出配置
- 螺桿 / 止逆環 / 雙合金
- TCO（有資料時）

## v4.2：產能、訂單交期與原料需求

新增「產能 / 原料」分頁，沿用選型資料直接計算：
- 理論產量 pcs/hr
- 稼動率後產量
- 良品率後實際良品 pcs/hr
- 每日良品 pcs/day
- 每月良品 pcs/month
- 訂單數量需要幾次 Shot
- 預估生產工時
- 預估需要幾個工作天

原料需求同時計算：
- 成品與不良品實際耗料
- 冷澆道水口總重量
- 水口回收比例
- 回收後需要補充的新料
- 開機 / 清料額外損耗
- 訂單建議準備原料 kg / ton

計算原則：
- 良品產能 = 理論產能 × 稼動率 × 良品率
- 訂單天數 = 訂單良品數 ÷ 每日良品數
- 所需 Shot 會把良率損失納入
- 熱澆道水口重量以 0 計
- 冷澆道可設定水口回收比例
- 原料最後再加上可設定的開機 / 清料損耗

產能與原料摘要也會帶進 A4 單頁選型 PDF。
