# OMC Smart Injection Advisor

OMC Smart Injection Advisor 是給超群機械（OMC）業務與客戶使用的射出成型前期評估工具。

## 線上體驗

👉 **[點我直接使用 Injection Advisor 網頁版](https://injection-advisor.vercel.app)**

## v2.1 架構

### 01 智慧選機 + 模具 + 廠房
- 五種產品資料入口：精準數據、2D 尺寸、克重 + 穴數、3D 數據、舊機置換
- 鎖模力與機台級距初步選型
- 模具柱間距 Fit Check
- 廠房長 / 寬 / 高與機台占地 Fit Check
- OS 系列機械尺寸資料：OS-50 / 80 / 110 / 140 / 180 / 250 / 320 / 420 / 550
- 模厚與開模距離欄位先保留，官方規格資料未補齊前不做猜測判定

### 02 Cycle Time / 產能分析
- 系統前期 Cycle Time 估算
- 支援客戶 / 現場實測 Cycle Time 覆蓋
- 穴數、稼動率、良率、每日工時、每月工作日
- 每小時、每日、每月良品產能
- 依客戶月需求估算設備數量

### 03 節能 / 電費分析
- 不寫死固定省電百分比
- 支援客戶實測、OMC 測試資料、人工估算
- 月 / 年減少用電
- 年電費差
- 節能比例
- 額外投資回收期
- 每 1,000 良品耗電估算

### 04 完整 OMC 評估報告
- 客戶 / 專案基本資料
- 選機、模具、廠房、產能、節能結果整合
- 未完成模組會標示未完成，不虛構數據
- 可直接匯出完整 PDF
- 另保留瀏覽器列印 / 另存 PDF
