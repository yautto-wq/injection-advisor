# OMC Smart Injection Advisor

OMC Smart Injection Advisor 是給超群機械（OMC）業務、工程與客戶使用的射出成型前期評估與現場調機輔助工具。

## 線上體驗

👉 **[點我直接使用 Injection Advisor 網頁版](https://injection-advisor.vercel.app)**

## v2.2 主要架構

### 01 智慧選機 + 模具 + 廠房
- 五種資料入口：精準數據、2D 尺寸、克重 + 穴數、3D 數據、舊機置換
- 鎖模力與機台級距初步選型
- 模具柱間距 Fit Check
- 廠房長 / 寬 / 高與 OS 系列機台占地 Fit Check
- 支援 2D DXF 上傳做外框尺寸初判
- DXF 結果必須人工確認後才可套用；DWG / PDF / JPG 目前只記錄檔案，不假裝已自動辨識
- OS-50 / 80 / 110 / 140 / 180 / 250 / 320 / 420 / 550 機械尺寸資料

### 02 Cycle Time / 產能
- 系統前期 Cycle Time 估算
- 現場實測 Cycle Time 可直接覆蓋
- 穴數、稼動率、良率、每日工時、每月工作日
- 每小時 / 每日 / 每月良品產能
- 依月需求估算設備數

### 03 現場調機助手
- 螺桿直徑、計量行程、計量效率 → 熔膠體積 / 重量估算
- 螺桿 rpm → 周速 m/s
- PP / ABS / PET / PC / PA+GF 材料工藝快查
- 乾燥、熔膠溫度、模溫等現場參數記錄
- 缺陷診斷：縮水、毛邊、短射、結合線、銀紋、燒焦、氣泡 / Void、翹曲、噴射紋、黑點、脫模不良
- 依案件資料對「先檢查什麼、再調什麼」排序
- 每次試模可記錄調整內容與改善結果，先儲存在瀏覽器本機

### 04 節能與 TCO
- 客戶 / 現場實測、OMC 測試資料、人工估算三種來源
- 舊機 / 新機平均 kW
- 每度電價、每日工時、每年工作日
- 舊機年電費、新機年電費、年省電費、年減少用電、節能比例
- 額外投資回收期
- 不用銘牌馬達功率冒充實際平均耗電

### 05 完整 PDF 報告
- 客戶 / 專案基本資料
- 選機、CAD / 模具、廠房、產能、調機、材料、節能 TCO 全部整合
- 未完成項目會標示未完成，不虛構數據
- 直接匯出完整 PDF，並保留瀏覽器列印 / 另存 PDF

## 2D CAD 支援說明

目前 v2.2 先支援 **ASCII DXF** 的圖面外框尺寸初判：
- 讀取 DXF 單位
- 優先使用 `$EXTMIN / $EXTMAX`
- 若沒有則用圖面座標做外框 fallback
- 顯示推算寬 / 高並要求人工確認後才套用到模具尺寸

注意：如果 DXF 含圖框、標註、表格或其他遠離模具本體的物件，整張圖的外框可能不是模具尺寸。下一階段可再做 layer / entity 選擇、模板輪廓辨識與尺寸標註解析。
